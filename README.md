# NerdScript

**Wiki Opener**

A little script for the curious minds who like discovering something new every day (well, unless you're the type who shuts down their PC at night). Wikipedia may not always be 100% accurate, but it's a great starting point for exploring new topics.

## What It Does

The script checks your internet connection three times over 15 minutes. Once it detects a connection, it opens a random Hebrew Wikipedia article alongside the main page.

**Note:** This script is built for Unix-like systems and may need tweaking to run on Windows.

## Requirements

- Python 3.x
- An internet connection

## Getting Started

1. Clone the repository:
   ```
   git clone https://github.com/on404/wikiopener.git
   ```
2. Move into the project folder:
   ```
   cd wikiopener
   ```
3. Run the script:
   ```
   python wikiopener.py
   ```

## Disclaimer

Wikipedia isn't infallible — treat it as a jumping-off point for curiosity, not a final source. Always verify important facts elsewhere.

Happy nerding! 🤓📚
